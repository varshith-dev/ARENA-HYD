# ARENA Hyderabad — complete laptop handoff

Download **ARENA-HYD-portable-windows.zip** for the project and tools in one archive. Extract it, then double-click **RUN-GAME.cmd** to play or **OPEN-EDITOR.cmd** to continue development.

Included: current source, original 36 street-view reference images, game assets, map datasets, development scripts and context, the last validated Windows / Android APK / web builds, Godot 4.7.2 with export templates, portable Python 3.11 and dependencies. `SHA256SUMS.txt` verifies the archive; the included `TRANSFER-MANIFEST.json` records every file's hash and the source commit.

Read **docs/NEW-LAPTOP.md**, **docs/HANDOFF.md** and **docs/CONVERSATION-CONTEXT.md** before continuing. Current source has newer collision work than the included binaries. Current headless gameplay and map validation pass; detailed obstacle checks and real-device testing remain. The moving metro, increased population and footprint infill are unfinished. Initial automated Street View images were blank and are marked unverified.

This is a development handoff, not a finished game release. Source and references are also available directly in the public repository. Android SDK/JDK, machine settings and credentials are not included.
